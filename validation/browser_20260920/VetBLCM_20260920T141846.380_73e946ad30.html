方法草稿Methods draft

鉴于缺乏完美参考标准，对 Simulated analyte 的两种检测结果采用贝叶斯潜类别模型进行评价。分析包含 3 个群体，以四格计数的多项分布为似然，采用 positive 模型，假设群体间检测性能和条件协方差恒定。使用 JAGS 4.3.1，经 rjags 4.16 运行 4 条链，每链适应 500 次、预热 1000 次、后验采样 2000 次，间隔 1 保留样本。下表列出实际先验及截断条件。报告后验中位数及等尾95%可信区间，采用posterior计算R-hat、bulk/tail ESS，并进行后验预测检验。条件依赖模型的结构不可识别性仍需外部信息支持；收敛与拟合检查不能证明可识别性。Because no perfect reference standard was available, results from two tests for Simulated analyte were analysed using a Bayesian latent class model across 3 populations. A multinomial likelihood was fitted to cross-classified counts using the positive model, assuming constant test accuracy and within-class covariance across populations. JAGS 4.3.1 through rjags 4.16 ran 4 chains, each with 500 adaptation iterations, 1000 burn-in iterations and 2000 sampling iterations, retaining every 1 iteration(s). Actual priors and truncation bounds are listed below. Posterior medians and equal-tailed 95% credible intervals are reported. Rank-normalized R-hat and bulk/tail ESS were calculated with posterior, and replicated multinomial counts were used for posterior predictive checks. For dependent models, structural non-identifiability requires external information; acceptable convergence and predictive fit do not establish identifiability. Methods follow Branscum et al. (2005) and the recorded WOAH guidance.

已知限制与警告Known limitations and warnings

  • Two dependent tests are structurally non-identifiable without additional information, regardless of population count / 两种依赖检测无额外信息时结构不可识别，增加群体不能消除此问题
  • Convergence/ESS targets not met / 收敛或有效样本量未达目标
  • No perfect gold standard; latent class meaning requires a defensible case definition / 无完美金标准，潜在状态需要合理的病例定义
  • Priors and test dependence can materially influence posterior estimates / 先验和检测依赖可显著影响后验
  • Constant accuracy and dependence across populations are assumptions / 群体间性能和依赖恒定属于假设
  • Prevalence separation and representative sampling are not guaranteed by risk labels / 风险标签不保证患病率区分或代表性
  • Clustering and specimen heterogeneity are not corrected by the basic model / 基础模型不校正群内聚集与样品异质性
  • Two-test dependent models remain structurally non-identifiable without additional information / 两种依赖检测没有额外信息时结构不可识别
  • Automated diagnostics cannot exclude all multimodality, bias or prior dominance / 自动诊断不能排除所有多峰、偏倚或先验主导
  • Agreement statistics are not diagnostic accuracy against a perfect reference / 一致性指标不能当作真实DSe和DSp

# Branscum et al. (2005) 3.3.3; positive feasible covariance parameterization.
# This two-test model remains structurally non-identifiable from likelihood alone.
model {
  for (t in 1:4) {
    accuracy[t] ~ dbeta(alpha[t], beta[t]) T(lower[t], upper[t])
  }
  Se1 <- accuracy[1]
  Sp1 <- accuracy[2]
  Se2 <- accuracy[3]
  Sp2 <- accuracy[4]
  uD ~ dbeta(alpha[J+5],beta[J+5]) T(lower[J+5],upper[J+5])
  uH ~ dbeta(alpha[J+6],beta[J+6]) T(lower[J+6],upper[J+6])
  UD <- min(Se1*(1-Se2),(1-Se1)*Se2)
  UH <- min((1-Sp1)*Sp2,Sp1*(1-Sp2))
  CovD <- uD*UD
  CovH <- uH*UH
  qD[1] <- Se1*Se2+CovD
  qD[2] <- Se1*(1-Se2)-CovD
  qD[3] <- (1-Se1)*Se2-CovD
  qD[4] <- (1-Se1)*(1-Se2)+CovD
  qH[1] <- (1-Sp1)*(1-Sp2)+CovH
  qH[2] <- (1-Sp1)*Sp2-CovH
  qH[3] <- Sp1*(1-Sp2)-CovH
  qH[4] <- Sp1*Sp2+CovH
  for (j in 1:J) {
    Prev[j] ~ dbeta(alpha[j+4],beta[j+4]) T(lower[j+4],upper[j+4])
    for (k in 1:4) {
      prob[j,k] <- Prev[j]*qD[k]+(1-Prev[j])*qH[k]
    }
    Y[j,1:4] ~ dmulti(prob[j,1:4],N[j])
  }
}
