# VetBLCM 0.1.9 统计原理与实现审查

审查日期：2026-09-28。对象：`[local working path omitted]`。本次只读审查原软件，在工作副本中运行验证，未修改 F 盘程序。

## 结论

在目前实现的“两项二分类检测、多个群体、各群体检测准确度与类内协方差恒定”的模型范围内，未发现核心似然、协方差参数化、Beta 先验转换或后验比较的原则性错误。现有核心无需推倒重写。发现两项应该修正的报告逻辑问题，均已用实际运行复现；它们影响报告可信度，不改变模型的后验抽样。

这不等于对任意真实数据均有效。尤其是两项检测同时允许感染与非感染类内的自由协方差时，数据本身不能一般性地识别所有参数；信息先验可以支持条件于先验的推断，但不会使似然自动可识别。软件已明确记录这个限制。

## 核心原理检查

| 环节 | 核对结果及适用条件 |
|---|---|
| 观测似然 | 每群体四格计数按 11、10、01、00 顺序使用多项分布；观测概率为患病率加权的两个潜在类别分布。正确。 |
| 条件独立模型 | 感染类以 Se 为阳性概率，非感染类以 1−Sp 为阳性概率，没有默认第二项检测是完美金标准。正确。 |
| 条件依赖模型 | 四格概率分别加、减、减、加同一类别协方差，保持边际概率和总和。正依赖模型使用非负可行范围；有符号模型使用完整 Bernoulli 可行范围。正确。 |
| 协方差界限 | 对边际 p1、p2，L=max(−p1p2,−(1−p1)(1−p2))，U=min(p1(1−p2),(1−p1)p2)。有符号模型 c=L+u(U−L)；u 是区间位置，不是相关系数。 |
| 先验 | α=mκ、β=(1−m)κ 的参数转换正确；κ=α+β 是 Beta 浓度约定，不应不加说明地当作真实外部样本量。截断后的均值、方差及分位数另行计算，处理正确。 |
| MCMC | 采用多链、独立记录的随机种子、分散初值及独立的适应和预热阶段；使用 rank-normalized R-hat、bulk/tail ESS 和适应完成状态。四链时 ESS 阈值为 400，R-hat<1.01。该诊断路线合理，但不能认证模型假设或消除未被访问的模式。 |
| 两检测比较 | DSe、DSp 差值来自同一后验抽样位置的相减，保留联合后验依赖，之后计算区间及 Pr(T1>T2)。正确。 |
| 模型检查 | PPC、先验敏感性、独立/依赖模型比较及人工审阅有各自用途；良好 PPC 和 MCMC 收敛均不证明结构可识别。 |

R-hat/ESS 的检查路线与 [Stan 官方诊断说明](https://mc-stan.org/learn-stan/diagnostics-warnings.html)一致；这里只借用通用 MCMC 诊断依据，没有把 Stan 专属的 HMC 诊断要求套到 JAGS。

核对了用户提供的 Toft、Jørgensen、Højsgaard（2005）全文，期刊页 19–33，DOI 10.1016/j.prevetmed.2005.01.006。其关于患病率差异、准确度恒定性和条件依赖可识别性的论述与上述边界一致。注意原文 p.30 Table 3 感染类左下格印为 −γSp，而同类其他格及观测概率表使用 γSe；按边际与概率和核验，该处应为 −γSe。软件使用感染类自己的 CovD，未照搬这一不一致。没有将原文作者对贝叶斯方法的广泛评价直接当作对所有现代 BLCM 的结论。

## 两项应修正的问题

### 1. 未知或矛盾的筛选人数被改写为“排除 0 人”

位置：`R/11_publication_outputs.R:31`，并涉及 `modules/mod_server.R:230` 的导入自动补值。

实际复现：分析纳入 6000 个样本时，筛选总数缺失，或错误填写为 5999，`sample_flow_table()` 都输出“筛选 6000、排除 0、纳入 6000”。未知不等于没有排除；后一种情形还是应向用户指出的数据矛盾。现有单元测试只覆盖了已知筛选总数的正常情形，未覆盖这两个边界。

建议：未知保持未知，流程图显示“未提供”；筛选人数小于纳入人数时报告错误，不静默修正。只有明确确认所有筛选样本均纳入时才允许自动写 0。其影响在样本流程图、表格和论文报告，不在四格计数似然。

### 2. 同一份先验证据在两张检查表中的判定不一致

位置：`R/11_publication_outputs.R:99` 的 `Priors` 条目，与 `R/06_sensitivity.R:34` 起的来源检查。

实际复现：清空信息先验的来源、依据、适用性及不确定性等字段后，正式审阅表 `Priors_documented=FALSE`，但 STARD-BLCM 辅助表仍显示 `Priors: Complete`。原因是后者只判断先验表存在且非空，不能支持“来源、不确定性及适用性已完整报告”的含义。

建议：复用来源审阅逻辑；只检查表存在时，应标为“先验表已记录，证据待审核”。同理，软件无法读取作者论文时，不应自动认证标题或摘要已满足规范。STARD-BLCM 是报告指南，而非软件自动授予研究合格的认证，参见 [EQUATOR 的官方指南入口](https://www.equator-network.org/reporting-guidelines/stard-blcm/)。

这没有绕过原有 `Priors_documented` 检查，也不能据此指控全部审阅机制失效；问题是附加报告发出了与正式检查相矛盾的完成信号。

## 最值得补充的一项科学验证

建议优先测试“假设不成立时会怎样”，尤其是比较检测先验的均值或强度有偏、以及 Se/Sp 在群体间变化。当前保存的依赖情景模拟使用正确居中的比较检测先验，浓度 400，主要说明在这些指定条件下的表现，尚不能回答先验转用到新群体后的偏倚风险。应预先指定真实参数、偏移幅度与重复次数，报告偏倚、区间覆盖率、区间宽度、诊断通过率，并保留不收敛结果；不要只汇总通过的结果。

这属于增强验证，不是修正核心公式。真实研究如已知存在明显群体准确度差异、同一动物重复检测或牧场内聚类，则应先调整研究分层或模型；目前这套恒定准确度、独立个体似然不会自动校正这些结构。不需要为了增加功能而无条件上层级模型。
